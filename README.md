# Saumitra Mishra

Personal portfolio: SAP data and analytics, BW/4HANA modernization, SAP Datasphere, Business Data Cloud and business AI architecture.

## Website

https://mishra-saumitra.github.io/

A responsive, buildless HTML/CSS/JavaScript site. No installation, API keys or backend is required.

## Run locally

```sh
python3 -m http.server 8000
```

## Update

Edit `index.html` for content, `styles.css` for layout, and `app.js` for interactions. Images and the client-anonymized resume are in the repository root.

## Design

Original implementation inspired by the dark portrait treatment and portfolio structure at https://pranzell.github.io/. All personal content and photographs represent Saumitra Mishra. Professional case studies are anonymized and distinct from public code projects.
